# Troubleshooting Guide

This section includes some common scenarios for troubleshooting and configuring MyWebSQL.

In case of Internal server errors, it is always a good idea to make sure you have error log settings configured in your PHP installation, and correctly defined the error log path in the php.ini file. If you see a blank page or internal server error, you should open the php error log and see the errors that come up. This usually gives you a better idea of how to fix the problem.

If you are unable to figure out the error message, you can copy and send them to us on the bug report page, along with the contents of the error log. We will try our best to provide a quick solution to you as soon as we can.
