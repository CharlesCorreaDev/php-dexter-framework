# Skill: Handoff 🔄

## Objetivo
Gerar um resumo executivo limpo e denso para passar o trabalho adiante sem perda de contexto ou alucinação.

## Estrutura do Handoff
1. **O que foi concluído:** Lista concisa de arquivos e features finalizados.
2. **Estado Atual:** Em que ponto exato o código ou arquitetura se encontra.
3. **Próximo Passo Imediato:** Qual a primeira ação que a nova sessão deve executar.
4. **Armadilhas & Atenção:** O que não deve ser alterado ou pontos de fragilidade identificados.
