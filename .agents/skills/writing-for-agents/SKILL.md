# Skill: Writing for Agents ✍️

## Objetivo
Escrever e atualizar documentações técnicas otimizadas para consumo de LLMs e agentes de IA, evitando ruído cognitivo e redundância.

## Regras Canônicas
1. **Ponto Central:** Todo conteúdo deve respeitar, alimentar ou derivar de [.agents/agent.md](../../agent.md).
2. **Alta Densidade e Sem Floreios:** Linguagem imperativa e direta. Modelos entendem regras concisas melhor do que parágrafos narrativos longos.
3. **Caminhos Relativos:** Todo arquivo deve ser linkado relativamente para portabilidade.
4. **Divisão Modular:** Separe tópicos densos em arquivos específicos dentro de `.agents/docs/` e referencie no `agent.md`.
